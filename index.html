LocalClipper

Turn long videos into short vertical clips, on your own computer.

LocalClipper is a personal, non-commercial desktop tool. It is not a hosted service and has no user accounts.

What it does

  • Transcribes a long video and picks the strongest moments, using AI models that run locally on the user's PC.
  • Reframes each moment to a vertical 9:16 video and adds captions.
  • Skips sponsor reads and ads.
  • When the user chooses to, uploads a finished clip to the user's own TikTok account, either to their TikTok drafts or as a post, using TikTok's official Login Kit and Content Posting API.

How it uses TikTok

The user connects their TikTok account by signing in on TikTok's own login page. LocalClipper only uploads a clip when the user clicks "Send to TikTok drafts" or "Post to TikTok" for that clip, and before a direct post the user picks the caption, who can see it, and the interaction settings on TikTok's required posting screen. The connection can be removed at any time with "Disconnect".
